# White Sportypo character clip art

36 transparent PNGs: a-z and 0-9, rendered directly from the supplied Sportypo-Reguler-Demo.ttf at 256 pixels.

The demo font does not provide readable numbers: its 0-9 glyphs are promotional logos. The user explicitly chose to export those original glyphs unchanged. These files are not replacement numeric artwork.

Each PNG imports as a single Unity Sprite. Use a UI Image with white Color and Preserve Aspect. Regenerate with Tools/GenerateSongSelectArt.py (Python/Pillow); existing GUIDs are preserved.
